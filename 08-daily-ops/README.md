# 8 - Daily Ops

The recurring rituals that keep a team moving.

| Prompt | What it does |
|---|---|
| [Backlog Grooming Assistant](backlog-grooming.md) | Triage and tidy a backlog: duplicates, stale items, missing detail. |
| [Retro Facilitator](retro-facilitator.md) | Facilitate a sprint retro with themes and prioritised actions. |
| [RICES Scorer](rices-scorer.md) | Score initiatives with a RICES framework for prioritisation. |
| [Sprint Planning Assistant](sprint-planning.md) | Plan a sprint from team capacity and a prioritised backlog. |
| [Stakeholder Update Generator](stakeholder-update.md) | Generate a stakeholder update from the week's progress. |
| [Stand-up Prep](standup-prep.md) | Prepare a crisp stand-up update from yesterday's activity. |
